# WeatherPatterns — готовый учебный проект

Проект демонстрирует MVC, MVP, MVVM и MVI на одной функции получения погоды.

## Как открыть
1. Распакуйте архив.
2. Откройте папку `WeatherPatterns` в Android Studio.
3. Дождитесь Gradle Sync. При необходимости установите Android SDK 35.
4. Запустите приложение на эмуляторе или Android-устройстве.
5. На стартовом экране выберите MVC, MVP, MVVM или MVI.
6. Проверьте Tashkent, Samarkand, Bukhara и Atlantis (для Atlantis ожидается ошибка).

## Важно
- Сетевой запрос имитируется; используется `FakeWeatherApi`, интернет не нужен.
- Искусственная задержка составляет 3 секунды, чтобы можно было проверить поворот экрана.
- Локальные unit-тесты находятся в `app/src/test`.
- В Android Studio откройте тестовый файл и нажмите зелёный значок Run либо выполните `testDebugUnitTest`.
- Gradle Wrapper в архив не включён: Android Studio обычно предложит использовать/создать wrapper при импорте проекта.
